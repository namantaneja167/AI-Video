Navigation map
Three levels: the workspace (left rail), one episode (journey stepper), and always-available drawers. Nothing is more than two clicks from the editor.
Workspace · left railAlways visible. Dark rail, one active item.
EpisodesList, status per stage, last render, open notes. “New episode” starts at Idea.
IdeasBacklog of topics with a learning objective and a verdict (go, park, drop).
LibrarySources, voice profiles, scene library, mascot kit, brand and sound kits.
Jobs · SettingsQueue, history, logs, retry. Paths, memory policy, backups, licences.
Inside an episode · journey stepper (9 stages, each reachable at any time; read in order, but never gated: the stepper shows state, it never blocks)Every stage shows done, current, stale or blocked. A stale stage links to the exact items to refresh.
1 Idea · 2 ResearchObjective, audience, hook. Sources with notes. Import ChatGPT research packets (paste or file). Items are Proposed until approved.
3 Script · 4 StoryboardSegments with caption text and spoken text. Storyboard assigns scenes to segments and proposes layouts.
5 VoiceBlocks, takes, pronunciation, pacing. Stale blocks regenerate selectively with a cost estimate. Approved voice reference is read-only.
6 Scenes (the editor)Outline · live preview · inspector · timeline. Layouts, mascot behaviours, beats anchored to words.
7 ReviewRendered MP4 with timestamped notes, rounds, automated checks. Notes re-anchor when the script changes.
8 Render · 9 ExportPreview ranges, final render, loudness master, captions, thumbnails, source package, checksums.
Always-available drawers and shortcuts Jobs tray (top right): progress, cancel, retry. Revisions (r14 menu): autosaves, milestones, diff, restore as a new revision. Notes: press N anywhere there is a playhead. Command palette (⌘K): jump to a segment, scene, job or note. Stale list: click any amber badge to see what is out of date and what it costs to refresh.
What each stage owns (artifacts)Idea → brief · Research → source packets · Script → segments · Storyboard → scene list + layouts · Voice → takes + timing · Scenes → scene params + beats · Review → notes + checks · Render → MP4 + frames · Export → package.
Design rules1. One primary action per screen. 2. Status is always visible, never hidden in a log. 3. Anything slow is a job with progress and cancel. 4. Nothing is deleted by an edit; stale artifacts stay until replaced. 5. The preview is live; the review is of a real render.
